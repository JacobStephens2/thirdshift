Themes

thirdshift console theme <name>

Edit the name and tokens, or paste an exported Theme. Save custom Themes to ~/.thirdshift/console/themes/. Copy fonts by hand into its fonts/ folder; name a file followed by its fallback stack, such as mine.woff2, sans-serif.
