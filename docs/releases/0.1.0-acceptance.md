# 0.1.0 release acceptance

Evidence for [issue #38](https://github.com/JacobStephens2/thirdshift/issues/38), collected on September 25, 2026.

## Release

- Annotated tag `v0.1.0` points to `91ac8634dd7b0df86e03810370fd71a6a3eae962`, the same commit recorded in the published crates.io package.
- [Release workflow run 36163872134](https://github.com/JacobStephens2/thirdshift/actions/runs/36163872134) succeeded, including the Rocky Linux 9 and WSL2/Ubuntu 24.04 smoke tests.
- The [GitHub Release](https://github.com/JacobStephens2/thirdshift/releases/tag/v0.1.0) contains the Apple Silicon macOS archive, static x86_64 musl Linux archive, shell installer, checksums, and distribution manifest. Its notes were generated from merged pull requests.
- The crates.io check logged `thirdshift 0.1.0 is already on crates.io; skipping`; the publishing job was skipped successfully.
- Standards and Spec reviews of the release pipeline found no actionable issues before tagging.
- Local validation passed: `cargo check --locked --all-targets`, `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings`, and all 104 tests in `cargo test --locked`.

## Installation and real Runs

Each machine installed through the published curl installer into `~/.local/bin`. On all three, `thirdshift version` printed `thirdshift 0.1.0`, and `thirdshift update` exited 0 with `thirdshift 0.1.0 is the latest release` on stderr.

The user selected an issue in a private repository for real Runs. The Runs were sequential: macOS created a pull request, then Ubuntu and Rocky continued its Issue branch. Private issue, PR, and session-log details are omitted from this public release record.

| Machine | Operating system | Run result |
| --- | --- | --- |
| Apple M5 Pro | macOS Tahoe 26.5.2, arm64 | Exit 0; PR ready for review |
| Ubuntu server | Ubuntu 24.04.4 LTS, x86_64 | Exit 0; PR ready for review |
| Rocky server | Rocky Linux 9.8, x86_64; kernel `5.14.0-687.51.1.el9_8.x86_64` | Exit 0; PR ready for review |
| WSL2 machine | Unavailable | Real Run not performed; workflow startup smoke test passed |

The acceptance repository has no CI checks. For all three Runs, thirdshift waited through its 60-second grace period, then verified that the PR was open, ready, and mergeable and cleaned up its worktree and local Issue branch.

These results validate thirdshift's installed Run lifecycle. The acceptance PR documents outstanding deployment work in that separate project; a successful thirdshift Run does not establish that the target project's live deployment is complete.
