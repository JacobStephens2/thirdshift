# Documentation

These guides are the shared reference for the repository and [thirdshift.app/docs](https://thirdshift.app/docs/). Choose a topic below, or start with the site's [visual walkthrough](https://thirdshift.app/how-it-works/).

- [Installation](installation.md): installing, updating, supported platforms and prerequisites, including unattended session permissions.
- [Commands](commands.md): starting a Run or Merge run, flags, output and exit codes.
- [Configuration](configuration.md): Setup, User config, [Harness, Model and Effort](configuration.md#harness-model-and-effort), and email.
- [Runs and delivery](runs.md): Worktrees, Claims, agent review, CI, Base fixes, Continuation, Failed runs and Spec runs.
- [Observing Commands](observing.md): status, show, logs and stopping work.
- [Scheduled work](passes.md): Architect, Security and Pickup runs, Weeding, Fencing and operating system schedules.
- [Development](development.md): building, testing, generating documentation and releasing.

The [domain glossary](../../CONTEXT.md) defines the terms used here. The [Session prompts](../../prompts/README.md) and [Factory skills](../../skills/) show exactly what the agent receives. Known gaps and planned work are tracked in the [open issues](https://github.com/JacobStephens2/thirdshift/issues).
