# Pass and fail use separate levels

At our Eval suite sizes, one 95% credible level makes even identical Arms hard to pass. Lowering that single level would also make noise more likely to fail an Experiment; widening the margin would let a larger regression pass. Following [the Bar decisions, Q2.3 and Q3.4](../grill-with-docs/1252-1253-bar-and-rechecks.md), the **Bar** instead fixes a **pass level** and a **fail level** before the first Trial.

Fail when the upper bound at the fail level is below zero. Otherwise pass when the lower bound at the pass level is above the margin and its upper bound reaches zero. Everything else is inconclusive. ([ADR 0025](0025-a-pass-needs-only-the-margin.md) drops the requirement that the upper bound reach zero.) Both intervals use the same paired Dirichlet draws, and the prediction of additional Eval tasks uses this same decision. The margin, prior, seed and draw count stay unchanged.

The fail level defaults to 95%. The pass level defaults to 70%, the floor of #1268's rule, because no higher level lets an A/A Experiment at #1370's measured disagreement pass 80% of the time on either suite (see docs/guide.md). This calibrates the pass without weakening the evidence for a fail. The method is `paired-dirichlet-v2`; saved Experiments using `paired-dirichlet-v1` retain their single-level Bar, intervals and stored Verdict when read. Their settings are never silently replaced with the new defaults.
