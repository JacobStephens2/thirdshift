Documentation

These guides are the shared reference for the repository and thirdshift.app/docs. Choose a topic below, or start with the site's visual walkthrough.

  • Installation: installing, updating, supported platforms and prerequisites, including unattended session permissions.
  • Commands: starting a Run or Merge run, flags, output and exit codes.
  • Configuration: Setup, User config, Harness, Model and Effort, and email.
  • Runs and delivery: Worktrees, Claims, agent review, CI, Base fixes, Continuation, Failed runs and Spec runs.
  • Observing Commands: status, show, logs and stopping work.
  • Scheduled work: Architect, Security and Pickup runs, Weeding, Fencing and operating system schedules.
  • Development: building, testing, generating documentation and releasing.

The domain glossary defines the terms used here. The Session prompts and Factory skills show exactly what the agent receives. Known gaps and planned work are tracked in the open issues.
